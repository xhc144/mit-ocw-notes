# 署名、许可与改动

主源为 Casey Rodriguez 授课的 MIT 18.102 *Introduction to Functional Analysis*, Spring 2021；笔记作者 Andrew Lin。采用 MIT OpenCourseWare 官方提供的 125 页合订本、23 讲 PDF/TeX 及原 TeX ZIP：[课程讲义目录](https://ocw.mit.edu/courses/18-102-introduction-to-functional-analysis-spring-2021/pages/lecture-notes-and-readings/)、[合订本下载页](https://ocw.mit.edu/courses/18-102-introduction-to-functional-analysis-spring-2021/resources/complete-lecture-notes/)。课程目录一句写作 Fall 2021，但课程标题、合订本和 TeX 许可头均为 Spring 2021；本项目采用 Spring 2021 并保留该差异记录。

辅助来源 Richard Melrose，*Functional Analysis: Lecture Notes for 18.102*, Spring 2020，version 0.9A，May 16, 2020；[官方资源页](https://ocw.mit.edu/courses/18-102-introduction-to-functional-analysis-spring-2021/resources/mit18_102s20_lec_fa/)。只对指定的弱收敛等条件作交叉核对，不宣称翻译全部 176 页。

MIT OpenCourseWare [使用条款](https://ocw.mit.edu/pages/privacy-and-terms-of-use/) 默认适用 [Creative Commons Attribution–NonCommercial–ShareAlike 4.0 International](https://creativecommons.org/licenses/by-nc-sa/4.0/)，另行标注的限制优先。原 TeX 明确保留 MIT OCW、课程及 “Creative Commons BY-NC-SA” 许可头；官方目录声明两套讲义经许可提供。逐文件许可依据及完整字节清单见 `source-manifest.json`。未检测到另行限制的页/图；许可检查依据与方法如实记录，并未将默认许可扩张到未知第三方材料。

中文改编于 2026-10-08 完成，由 xhc144 的 MIT OCW 讲义归档项目组织译编。译文、重排正文、补全的论证及新绘数学图按同一 CC BY-NC-SA 4.0 许可提供。主要改动为：简体中文翻译、按概念依赖重排、补全略写的证明、增加带解答的例题/练习、显式区分测度先修、重绘投影与 Fejér 核、修正原笔记若干符号和条件错误。具体原讲页码、补充范围及勘误见书末“来源与改编”。

本次保留原12章及30份既有例题/习题解答，扩展收入 Casey Rodriguez 课程的[全部10份作业、期中测验、期末作业](https://ocw.mit.edu/courses/18-102-introduction-to-functional-analysis-spring-2021/pages/assignments-and-exams/)，以及[大纲](https://ocw.mit.edu/courses/18-102-introduction-to-functional-analysis-spring-2021/pages/syllabus/)与[日历](https://ocw.mit.edu/courses/18-102-introduction-to-functional-analysis-spring-2021/pages/calendar/)中的课程信息。12个官方PDF共36物理页、54道编号题、87个字母子问及18道未分问单题，共105个解答单元。原题面保留 MIT OCW 署名页；逐文件实际下载URL、页数、字节与SHA见 `assessment-inventory.json` 及 `source-manifest.json`。每页进行了文本与独立权利标记检查，12份均无嵌入图像、未发现另外限制；许可依据是官方条款及原件的OCW课程署名，不声称PDF自行印有完整CC许可证全文。

官方目录没有配套答案。新增中文题解均注明 **AI 独立解答**，其条件、证明及与旧解答的对应经过独立Sol数学复查；这是项目编者提供的补充，不是MIT教师官方答案。对源题箭头、从上连续名称、范数漏印和子列证明笔误作显式勘误；作业9空闭凸集的原命题为假，先给反例，再明确增加非空条件。期末材料按官方资源页及大纲称“期末作业”，保留其PDF内使用exam措辞的差异记录。

原件以下载字节归档，原有署名与许可头保留。中文 ZIP 为单独干净源码，排除原 ZIP 的 macOS 元数据、字体、编译缓存与页面截图。固定模板及既有工具的来源文件保留其各自原有说明；文档许可不更改运行字体或外部软件的许可。

本改编未获 MIT 官方认证；保留署名不表示 MIT 或原作者认可译编内容。使用时应保留原课程、作者、来源、许可链接及改动说明，遵守非商业和相同方式共享条件。
