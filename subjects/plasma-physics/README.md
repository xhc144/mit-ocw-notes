## 完整性与范围

2006站点同时列2002/2005历史练习和答案，2007另列2003历史期末；这些登记但未全部翻译，不冒称当期官方答案。没有实际取得对应官方答案的60题组均明确为独立补解。22.615的HW1—5仅有十二个商业教材引用题号，完整题面未公开取得，逐项列缺：5.5/5.8/5.9、6.2/6.5/6.11、6.17/6.18、8.6/8.7、9.3/9.4。没有猜造题面或用英文原件充作中文交付。

NRL Formulary 2002的课程外链指定页被代理403阻断；作业四已给独立冲量推导、单位与频率定义比较方法，未声称完成原页逐式核对。课程原图没有整页贴入：图为TikZ/PGFPlots新绘或原创代码生成的矢量图。原题存在系数/符号或数据不相容时分别说明，模型限制保留；例如Spitzer电阻、E漂移的能量排序、剪切层符号、准中性数密度、2006期末截止/共振位置以及2007的GS压力系数。

MHD期中采用官方Help允许的余弦矩与λ=.2分支，得到fB=.75时β=4.5542%，超过题给Troyon的4.1757%，外驱动需81.67MW。其强形式GS相对RMS残差.16978明确保留，弱矩收敛不冒称完整PDE精确解。期末给显式3×3矩阵，实际扫描15,251个平衡，确认52个零特征值点、122个壁分支跳变；有限试探空间和候选上确界不能推广为全MHD最高稳定值。
