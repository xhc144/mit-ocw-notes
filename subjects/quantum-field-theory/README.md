# 量子场论：从局域场到重整化群

[中文合订 PDF](quantum-field-theory-zh.pdf) · [独立 LaTeX 源码 ZIP](quantum-field-theory-source.zip) · [逐套覆盖与缺口](coverage.md) · [来源清单](sources/source-manifest.json) · [审校证据](qa/README.md)

全册 **148页，19章连续理论、19套作业记录与题解**。从相对论和经典场论的最短先修补充起步，贯通标量与Dirac场、传播子、路径积分、散射与QED，再进入非Abel规范场、BRST、谱表示与LSZ、重整化和重整化群。正文使用仓库固定中文数学LaTeX版式，图采用可编辑TikZ。卷首列教师、学期、原课先修、大纲进度和考核方式。

本轮选定 Hong Liu 的 MIT OCW **8.323 Spring 2023** 与 **8.324 Fall 2010**：前者26讲公开主题、12套作业及匹配公开解，后者26份实际讲义、7套作业及匹配公开解。中文按概念重编，补充完整主推导与计算，既不是原英文PDF拼接，也没有宣称逐分钟转录所有视频或完成MIT全部量子场论课程。

逐题读原件、复算和独立模型审读后的计数是 **71道原大题：63道全题面全解、2道混合题仅完成公开子问、6道全为商业教材指针**。共 **200个可获最外层题问单元**给出推导，另13个最外层单元只有商业教材指针。嵌套子问不重复计数，未知商书内部子问不猜测。大题按每套原编号计，8.324作业6原题4与作业7原题1重复，仍分别保留。8.324第5套全部属于题面缺口，保留真实定位，没有从答案反造题面。作业中文答案依据公开官方解重编并附独立补充、归一与符号核查；不是MIT官方中文版。

两门课大纲均明确没有考试。8.324大纲所称第8套未在公开列表提供；8.323习题课9明确不可得，另外九份习题课笔记只归档供参考，没有冒称逐页翻译。所查视频资源页没有字幕下载链接，本次保留官方视频链接而不打包视频。具体来源边界见[覆盖清单](coverage.json)。

73份官方PDF、435页已实际下载解析并再次逐文件核对SHA256、字节数和页数，原件保存在本学科的[sources](sources/)。保留MIT OCW、Hong Liu及Wentao Cui信用，第三方例外检查的方式与限制见[来源许可说明](sources/SOURCE-LICENSE.md)。原件与中文改编按[CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)用于非商业共享；商业教材、字体和未审计历史课程PDF没有打包。
