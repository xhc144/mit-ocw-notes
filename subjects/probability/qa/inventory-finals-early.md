## 原稿勘误及写作补全候选

- 2011 Q9.b（解答 PDF 第 3 页，数值错误）：官方σ²=3却写μ=-9/2；应为μ=-3/2。
- 2011 Q7.b（解答 PDF 第 3 页，未完成计算）：官方只说计算log Y1再乘10000，未给出均值方差；应补-10000log2/3与(80000/9)(log2)²。
- 2012 Q5.a（解答 PDF 第 3 页，支持区间笔误）：PDF原稿写-1≤x≤-1，应为-1≤x≤1；密度系数原PDF是2/π，不能被抽取误读为1/(2π)。
- 2012 Q4.c（解答 PDF 第 3 页，符号笔误）：所求为Var(Y)，官方末句写Var(S)=3，值3正确。
- 2014 Q3.c（解答 PDF 第 2 页，末项符号错误）：无人拿帽概率最终写-1/8!，应为+1/8!；正确值14833/40320。
- 2014 Q4.a（解答 PDF 第 3 页，起始值笔误）：停时公式第一句写Y0=1；随机游走从0开始，后续已正确写0，答案3/16正确。
- 2014 Q5.a（解答 PDF 第 3 页，密度分布符号混淆）：将4exp(-4t)写成F_Z(t)，应为f_Z(t)；分布函数为1-exp(-4t)。
- 2014 Q8.a（解答 PDF 第 4 页，指数与参数笔误）：官方写E[e^{tX}]=积分密度乘e^{-x}，应为E[e^X]=积分密度乘e^x；由于均值0，错误负号碰巧同值e^{5/2}。
- 2014 Q8.b（解答 PDF 第 4 页，奇次幂笔误）：题目含X³，解释却写E[X⁷]=0；应写E[X³]=0，最终7正确。
- 2014 Q10.b（解答 PDF 第 5 页，方差对象符号错误）：计算的是Var(log X1)，原稿写Var(X1)，后续对log Y400的方差数值正确。
- 2016 Q4.a（解答 PDF 第 2 页，中间概率笔误）：已正确说明第二只鞋异类概率n/(2n-1)，随后两次写E[Ai]=2/(2n-1)，应为n/(2n-1)；最终E[B]=n²/(2n-1)正确。
- 2016 Q4.b（解答 PDF 第 2 页，边界情形需补）：官方二阶矩公式含2n-3，对n=1单独得B=1，E[B²]=1；一般推导适用n≥2。
- 2016 Q7.a（解答 PDF 第 3 页，阈值笔误）：官方写P(A>5)=P(X>5,Y>5,Z>5)=((5-a)/5)^3；其中各5应为a，密度结果正确。

## 抽取恢复重点

- 2011 Q7(a) 下边界为 1/8；Q7 的 Yn 为乘积。
- 2012 Q2(b) 的(ii)(iii)为乘积、(iv)(v)为求和；Q9(b)含事件指示函数。
- 2014 Q4(b)(ii)为 5^{-n}∏Xi、(iii)为∏Xi²；Q9(c)为 H(2^X3^Y)，Q10(a)下边界为 1/64。
- 2012 Q5(a)的 2/π 系数属于抽取损失，但右端 -1 属于原稿笔误；不可混同。
- 2011 Q7(c) 的“大于中位数”是离散分布的 CLT 近似，约 1/2；后续正文须说明离散点质量，并避免称为精确等式。
