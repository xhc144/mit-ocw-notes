# 量子力学：波函数、态空间与近似方法

从[一本连续中文讲义 PDF](quantum-mechanics-zh.pdf)开始阅读。全册89页，17章理论、19章考核题解与来源附录，采用固定中文数学 LaTeX 模板。主轴为 Barton Zwiebach 的 MIT OCW 8.04 Spring 2016 → 8.05 Fall 2013 → 8.06 Spring 2018；从干涉观察、复数振幅、概率与波函数开始，逐步建立算符、测量、角动量与近似方法。卷首保留教师、学期、先修、大纲、课历和考核方式。

[可编辑源码 ZIP](quantum-mechanics-source.zip) · [覆盖清单](coverage.json) · [编译方法](BUILDING.md) · [审校记录](qa/release.json)

当前保留且有完整题面的19份作业、测试和期末卷，共112道大题全部小问，已有中文转述和逐题解答。两张公式表另行归档。解答全部标为 **AI 独立解答**，没有取得所选课程的官方答案。正文补入打靶与节点排序、δ势、相干和压缩、三种动力学表象、角动量合成、氢精细结构三项、Berry相位、Airy转折点连接、带电粒子、散射及全同粒子应用；数值曲线和能级图用TikZ重绘。

正文与考核经过独立模型复核及返修；各记录绑定实际源哈希。成品的自动模板检查、逐页视觉记录、198个内部链接与195个书签的检查结果，以及源码包重建证据，集中在审校记录中。自动编译与数值采样不能替代数学证明，独立模型复核没有人工专家认证的含义。

本册按概念重编，覆盖边界逐项列在册末与清单；没有宣称三课每页逐字翻译。Airy复路径变形、非终止超几何级数增长、低能Dirac有效项、Runge–Lenz长算符恒等式明确作为进阶输入；其后的计算展开推导。场论、辐射修正及完整多体理论未纳入这本学习册。
