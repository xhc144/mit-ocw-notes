## 极值章的逐段审读

| 单元 | 实际检查内容与结论 |
| --- | --- |
| Mantel | 无三角形时每边两端邻点集不交，沿边求和左边等于 Σd(v)²；Cauchy–Schwarz 给 m≤n²/4，m=0、n=0 单独成立；平衡二部构造达到整数界。 |
| 精确 Turán | 二级极值为孪生类大小平方和。等开邻点集必为独立类；非邻接不等度时单点复制增边且不造更大团。等度非邻接两类 A、B 整类复制不改边数、不产生禁团、不拆其他类，而合并使平方和至少增加2\|A\|\|B\|。所选极值图因此完全多部，部数≤r；平衡平方和给精确 t_r(n)，含 n=0、r=1、r>n。10点禁K4例题为4、3、3分部、33边。 |
| Kővári–Sós–Turán | 逐邻点s子集双计数；公共邻点与该子集不相交由无自环保证。整数二项式下界 (d−s+1)_+^s/s! 与该凸函数的 Jensen 应用均合法。平均度≤s−1 和 n=0 分支处理后常数为 (t−1)^{1/s}/2 与 (s−1)/2；不用隐含 s≤t 条件。 |
| 有限域无C4构造 | 点侧与线参数侧独立标号，顶点2q²、边q³。不同横坐标的两点唯一确定斜率和截距；相同横坐标不同纵坐标没有共同非竖直线。两点至多一共同邻线排除四圈，常数 n^{3/2}/(2√2) 正确。只声明素数q及相应顶点数序列，没有宣称每个n或最优常数。 |
| 两题解答 | 随机二分期望m/2、保留跨侧边确实二部，C5反例有效。无C4共同邻点双计数给平均度约束，再解二次式得 n(1+√(4n−3))/4；题面已明确 n≥1。 |
