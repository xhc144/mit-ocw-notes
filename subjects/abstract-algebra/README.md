14个理论章节贯通群、陪集与商群、置换、群作用与Sylow、环与理想、分解整环、多项式、模、PID上有限生成模、域扩张、有限域、Galois对应及素性检验基础；再有作业、模拟考试、来源边界三章。核心定理给出证明，保留经典例题和带解答练习。书前附大纲、先修、课时、教材、评分与教学进度。第18章是自足的独立GFDL四题附录。

主源 James McKernan 的18.703 Spring 2013，23份教师讲义共149页。补充 RES.18-011 Fall 2021（178页）和 RES.18-012 Spring 2022（162页）的选定主题；两册学生笔记官网明确未经教师核准，已独立数学交叉审读。不是所有原件逐页全译。

11份官方作业与3份模拟卷中的 **69个MIT公开题号、116个明确小问**全部有中文题面与完整题解，保留课程、学期、原编号、分值、时长。重复去除后为68个不同公开题。解答为编者独立推导并经交叉审读，**不是官方答案**。原有81个只给外书定位的题号（80个不同定位）保持单独统计。

本次实际新增 **4道Judson题、8项解答任务**：作业1第3、4、10题与作业2第14题（J第3章#5、#10、#48、#50）。题面、正方形对称群64格乘法表、矩阵群证明和准循环群子群分类均完整，并独立审读。四题在作者2012、2013历史版一致，不据此断言教师当年采用哪个版次。作业1第11题（J#49）两版不同，明确保留冲突，不用候选题替代。其余Herstein题面仍未获取。原MIT公开题统计仍为69；合册实际解答73个来源题号（72个不同题），共116个原明确小问加8项新增任务。仍未恢复77个外书定位题号（76个不同定位，含#49）。

未完整覆盖一般自由群构造、一般AKS参数与复杂度证明、正交几何与Lie群、一般Noether/Hilbert基定理、数域理想类群、函数域几何、一般根式求解及判别式理论；群表示与特征标另册处理。线性代数仅作模论必要先修，不重做数值线性代数。讲次对应、编者补证及源文件数学勘正见第17章。

## 重编与许可

解压后进入 `abstract-algebra/`，运行 `bash build.sh`。需要 XeLaTeX、ctex、amsmath、amsthm、fontspec、TikZ、booktabs、longtable 等常见TeX Live包、Fandol中文字体和Computer Modern Unicode字体（`cmunrm.otf`等）。模板类内嵌；三轮编译生成 `dist/main.pdf`，不依赖其他科目、网络或shell escape，不分发字体。空目录实测重编的全部58页文字、渲染及目录与成品相同。
