14 个理论章节依次建立群、陪集与商群、置换、群作用与 Sylow、环与理想、分解整环、多项式、模、PID 上有限生成模、域扩张、有限域、Galois 对应及素性检验基础。另有课程作业、模拟考试和来源边界三章；书前附官方大纲、课时、先修、教材、评分与完整教学进度表。核心定理均给证明，保留经典例题及带解答练习。

主源为 James McKernan 的 18.703（2013 年春季）23 份教师讲义，149 页。补充采用 RES.18-011（2021 年秋季，178 页）和 RES.18-012（2022 年春季，162 页）的选定主题。后两册为学生笔记，官网明确未经教师核准；本册进行了独立数学交叉审读。

官方 11 份作业与 3 份模拟卷中的全部 **69 个公开题号、116 个明确小问**均有中文题面和完整题解，保留原课程、学期、题号、分值和考试时长。相同题去重后为 68 个不同公开题。全部解答为本次编者独立推导并经交叉审读，**不是官方答案**。另有 81 个只给教材定位、未公开题面的原题号（80 个不同教材题定位），逐项登记，不臆造题面。课程网站没有在所选页面提供正式期中、期末卷或答案。作业 11 原 PDF 误写标题“作业 9”，清单保留此差异。

本册并非所有原件逐页全译。未完整覆盖一般自由群构造、一般 AKS 参数与复杂度证明、正交几何与 Lie 群、一般 Noether/Hilbert 基定理、数域理想类群、函数域几何、一般根式求解及判别式理论；群表示与特征标留给另册。线性代数仅作模论应用先修，不重做数值线性代数。完整讲次对应、编者补证及源文件数学勘正见第 17 章。

## 重编

解压源码 ZIP 后进入 `abstract-algebra/`，运行 `bash build.sh`。需要 XeLaTeX、ctex、amsmath、amsthm、fontspec、TikZ、booktabs、longtable 等常用 TeX Live 包，以及 Fandol 中文字体和 Computer Modern Unicode 字体（`cmunrm.otf` 等）。模板类嵌在 `main.tex` 中；不依赖仓库其他科目，不需要网络或 shell escape，不分发字体。脚本运行三轮，生成 `dist/main.pdf`。当前执行环境的本地 TeX 树和字体缓存通过环境变量提供，具体验证命令见 QA；这不是源码包对绝对路径的依赖。
