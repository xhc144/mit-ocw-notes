# 抽象代数官方来源归档

选定 41 个资源文件：39 个 PDF，共 **545 个实际页面**，以及 2 个官方 TeX ZIP。逐文件 URL、实际页数、作者、许可检查、SHA256 及 ZIP 成员清单见 `source-manifest.json`；归档的 HTML 与抽取文字见 `archive-inventory.json`。

- 18.703 Modern Algebra，Spring 2013，James McKernan：23 份不同教师讲义，149 页；第 24 讲为复习，没有 PDF。
- RES.18-011 Algebra I Student Notes，Fall 2021：合订 PDF 178 页及官方 TeX ZIP。学生记录 Jakin Ng、Sanjana Das、Ethan Yang；讲课教师 Davesh Maulik。
- RES.18-012 Algebra II Student Notes，Spring 2022：合订 PDF 162 页及官方 TeX ZIP。学生记录 Sanjana Das、Jakin Ng；讲课教师 Roman Bezrukavnikov；笔记工作由 Ashay Athalye 监督。
- 18.703 官方 11 份作业，24 页；3 份模拟卷，32 页。没有冒充正式考试卷或官方答案。题面缺失、重复与原编号差异见中文册 `assessment-map.json`。

两组学生笔记均未经教师核准。只选合订 PDF，单讲 PDF 未另行重复归档；TeX 包是相同笔记的另一格式。资源页、课程大纲、教学进度、阅读页、作业页、考试页和使用条款另存于 `html/`，用于署名、范围与许可核对。所有英文 PDF/TeX ZIP 仅作来源归档，**不包含在中文源码 ZIP 中**。

默认 CC BY-NC-SA 4.0；单件第三方例外优先。逐文件检查了可见版权/许可/来源标记，未发现另行明确限制的单件声明，不因此推定未标注材料或外部教材也获得授权。未获取 Herstein/Judson 教材文件；未复用原图。
