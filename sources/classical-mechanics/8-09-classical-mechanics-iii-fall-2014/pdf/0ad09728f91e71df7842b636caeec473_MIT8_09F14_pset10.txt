5. Chaos in Maps [15 points] 
We have seen that chaos from 1st order diﬀerential equations requires 3 variables 
and nonlinearity. Instead consider a discrete set of points {xn} determined by a 
map, xn+1 = f(xn). Here chaos can occur for a nonlinear function f(x) with only one 
variable x. You can picture why this might be the case by recalling that for the driven 
damped nonlinear oscillator we saw chaos when we plotted a discrete set of points ωn 
versus the control parameter a (with values obtained from Poincar´e sections).
