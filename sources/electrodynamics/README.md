# 电动力学原始资料

本科主线为 MIT OCW **8.07 Electromagnetism II, Fall 2012**, Alan Guth 与 Min Chen; 进阶来源为 **8.311 Electromagnetic Theory, Spring 2004**, Leonid Levitov. 中文重编不代表 MIT 官方中文或 MIT 认可.

本批实际下载并解析验证 63 份 PDF, 其中 61 份可取得的 MIT 原件进入仓库. 2 份含明确 YouTube 许可例外或商业教材扫描题面的候选仅记录官方链接、SHA-256 和页数, 未将完整原件打包. 原件和网页快照的逐项来源、作者、学期、许可边界及文件路径见 `../../manifests/electrodynamics-sources.json`.

8.07 公开 10 份作业、Quiz 1、Quiz 2、Final Exam 和两次 Quiz 的官方解答. 本科作业和期末官方解答未发现. 不补造仅列 Griffiths/Jackson 题号的缺失题面. 8.311 原件包括 4 份补充讲义、12 份作业及 12 份官方解答、期末及其官方解答. 该课不提供全套理论讲义, 不据此宣称已获得完整研究生课程文本. 本次未定位可核实的 8.312 OCW 课程.
