`source-manifest.json` 登记全部10个官方PDF的URL、字节数、SHA-256、页数、署名及许可核查，并保存6个官方网页档案的校验值。`assignments-manifest.json` 登记11次作业52题（含选做）和4道期末题。`text/` 是定位辅助；公式符号和图形条件均须回查原PDF，不能把有损字符抽取当作题面。

旧讲义与期末末页指向 MIT OCW 条款；依当前默认 CC BY-NC-SA 4.0，单独权利标记优先。本次两份归档原件未发现另外的第三方转载限制。参考书目中的书籍不因此获准复制。官方另链的2016年AMS出版书明确禁止上传至非作者网站，未下载、归档或改编。该出版书与本档案109页公开旧讲义不是同一版本。
