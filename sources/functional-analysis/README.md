目录中重复出现的第一讲链接指向同一文件，只归档一次。全部文件位于 `18.102-spring-2021/`，用官方文件名保留识别信息。[source-manifest.json](18.102-spring-2021/source-manifest.json) 逐项记录精确下载 URL、资源页 URL、字节、SHA-256、页数和许可检查；PDF 页数由实际下载文件计算，全部 49 个文件已本地复核哈希。

课程目录一句写作 “Fall 2021”；课程 metadata、合订本与 TeX 头一致为 Spring 2021，本归档采用 Spring 2021，并在清单记录冲突。Melrose 辅助讲义为 Spring 2020，version 0.9A，run May 16, 2020，保留其独立年份。

官方目录说明讲义经许可提供。MIT OCW 的 [使用条款](https://ocw.mit.edu/pages/privacy-and-terms-of-use/) 默认为 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/)，另行标注限制优先。原 TeX 含明确 CC BY-NC-SA 署名许可头；25 个 PDF 全文进行了版权/限制标记检索，未检测到文件内例外。原 ZIP 中的 Fejér 示意图已检查；中文册以 PGFPlots 重绘。没有另行受限图页被无依据地复制进中文册。下载页 HTML 与官方条款 HTML 留作来源快照。

[中文完整 PDF 与干净源码包](../../subjects/functional-analysis/README.md) 与原件归档分开管理。中文册覆盖主源泛函分析主线；测度构造按用户指定作为实变先修接口，不宣称逐字翻译原件所有测度页，也未宣称覆盖辅助书的所有高级专题。署名与具体改动见 [ATTRIBUTION.md](../../subjects/functional-analysis/ATTRIBUTION.md)。
